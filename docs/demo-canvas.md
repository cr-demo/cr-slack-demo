# Cakes & Cocktails: make something together

A little sweet. A little spirited. Coding is multiplayer — help us write the next page.

## 1. Meet the app
In this code channel, ask:

> @CodeRabbit What does the app in this repository do, and how does it work? Keep it brief and point me to the recipe data.

## 2. Add your flavor
Choose a cake or cocktail, or try:

> @CodeRabbit Add a rum Old Fashioned recipe with ingredients, quantities, instructions, and a short description. Follow AGENTS.md and open a PR.

Want credit? Add “Use [your display name] as the contributor.” Follow up in the same thread with a preference, such as “Make it less sweet.”

## 3. See the contribution ship
Explore the diff and PR with the presenter. Use the connected agent's Drive to completion action if available to address review feedback. After the presenter reviews and merges, they pull the repo and refresh the local cookbook. Your contribution joins the collection.

## Presenter notes
- Start the coding request early. While it runs, show a clearly identified prepared thread demonstrating a request, code diff, review feedback, and fixes. Do not present prepared output as the attendee's live request.
- Keep prepared threads and a completed example PR available. Coding may exceed a three-minute session; return to its real progress without promising completion timing.
- Pull and refresh is the local update path. This app does not render GitHub HTML file views or automatically receive Slack messages.
- Four laptops should have separate checkouts. Multiple contributions can share the repository, but inspect merge conflicts in recipes.js and validate the final combined data.
- Keep contributions across sessions. Reset the browser search/filter and close dialogs for the next attendee; do not erase merged contributions. Favorites are per browser and can be untoggled.
- Test channel/thread memory and repository permissions in the actual Slack/CodeRabbit setup. No reset automation is included here.
- Ask code questions while waiting: “How does search work?”, “Where are favorites stored?”, or “Does this app send any data to a server?”
- Keep the booth checkout clean. After an authorized merge: `git pull --ff-only`, then browser refresh. Do not hard reset or force-pull over local work.
